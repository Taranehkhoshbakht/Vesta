## ☁️ استقرار روی Cloudflare (Workers + KV)

این پروژه دو نسخه دارد:
- `server.js` — نسخه Express برای VPS/لوکال
- `cloudflare/worker.js` — نسخه Cloudflare Worker (بدون سرور، روی CDN جهانی Cloudflare)

### مراحل استقرار روی Cloudflare

**۱. نصب وابستگی‌ها و ورود به Wrangler:**
```bash
npm ci
npx --yes wrangler@4 login
```

**۲. ساخت دیتابیس KV:**
```bash
npm run cf:kv
```
خروجی یک شناسه می‌دهد. آن را در `wrangler.toml` زیر `[[kv_namespaces]]` با `binding = "DB"` قرار دهید؛ یا KV را از داشبورد Cloudflare با نام دقیق `DB` به Worker وصل کنید.

**۳. بررسی و تست لوکال (اختیاری):**
```bash
npm run cf:dry-run
npm run cf:dev   # http://localhost:8787
```

**۴. انتشار:**
```bash
npm run cf:deploy
```
بعد از انتشار، سایت روی آدرسی مثل `https://vesta.<your-subdomain>.workers.dev` در دسترس است. می‌توانید در داشبورد Cloudflare دامین اختصاصی هم وصل کنید.

> 💡 **نکته:** در اولین بازدید، دیتابیس KV به‌صورت خودکار با محصولات و حساب‌های مدیریتی نمونه ساخته می‌شود (همان شماره‌های بالا). کد تایید در حالت دمو روی صفحه نمایش داده می‌شود — برای نسخه واقعی، در `cloudflare/worker.js` بخش `request-otp` را به سرویس پیامک (مثل کاوه‌نگار/ملی پیامک) وصل کنید.

> ⚠️ **محدودیت KV:** دیتابیس کل فروشگاه در یک کلید KV ذخیره می‌شود — برای فروشگاه کوچک/متوسط عالی است. برای ترافیک بالا، مهاجرت به D1 (SQL) پیشنهاد می‌شود.

## 📱 موبایل‌فرست و PWA

سایت برای کاربران موبایل بهینه‌سازی شده (طبق آمار، ۹۵٪ ترافیک موبایلی):

- **ناوبری پایین جزیره‌ای و شناور:** خانه، دسته‌ها، سبد، علاقه‌مندی، حساب کاربری
- **هدر جمع‌وجور موبایل:** منوی همبرگری، لوگو، جستجو و سبد؛ دسته‌ها در منوی کناری
- **گرید ۲ ستونه محصول** در موبایل، ۳ در تبلت، ۴-۵ در دسکتاپ؛ گرید محصولات بلافاصله پس از هیرو می‌آید
- **تصاویر اولویت‌دار در موبایل** با تصویر جایگزین محلی برای زمان قطعی یا کندی تصاویر خارجی
- **اسکرول افقی** برای فروش فلش
- **فیلترها در شیت پایین‌کشیدنی** (Bottom Sheet) به‌جای سایدبار
- **دکمه‌های لمسی ≥ ۳۸px** و فونت ورودی‌ها ۱۶px (جلوگیری از zoom خودکار iOS)
- **پشتیبانی از safe-area** (نوار پایین آیفون)
- آیکون‌ها همگی **SVG اینلاین** (بدون وابستگی به فونت ایموجی)

### PWA
- `manifest.json` + آیکون‌های ۱۹۲/۵۱۲ و maskable
- **Service Worker** با استراتژی: API = شبکه، تصاویر = cache-first، منابع سایت = stale-while-revalidate
- صفحه **آفلاین اختصاصی** (`offline.html`)
- **بنر نصب** برای اندروید (beforeinstallprompt) و راهنمای دستی برای iOS
- میان‌برهای اپ (سبد، پروفایل، علاقه‌مندی‌ها) از منوی لمس طولانی آیکون
